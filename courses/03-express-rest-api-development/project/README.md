# Express.js & RESTful API Development - Learner Project

This project uses challenge stubs only. Learners implement each challenge in `src/challenges/*` and validate through review automation.

## Module Coverage

- **Express.js Fundamentals**
  - Express application setup and configuration
  - Routing: route parameters, query strings, route handlers
  - Middleware concepts: built-in, third-party, custom
  - Request/response cycle and middleware chain
  - Static file serving and template engines basics
- **REST API Design & Implementation**
  - RESTful principles and resource design
  - HTTP methods: GET, POST, PUT, PATCH, DELETE
  - Status codes and proper response formatting
  - API versioning strategies
  - CORS configuration and handling
  - Content negotiation and Accept headers
- **Database Integration**
  - PostgreSQL with pg or node-postgres: connection pooling, parameterized queries
  - MongoDB with Mongoose: schemas, models, validation, middleware
  - SQL vs NoSQL decision framework
  - Database design patterns: normalization, indexing strategies
  - Query optimization and N+1 problem solutions
  - Transactions and ACID compliance
- **Authentication & Security**
  - JWT (JSON Web Tokens): creation, verification, refresh tokens
  - Password hashing with bcrypt
  - Session management and cookies
  - OAuth 2.0 integration basics
  - HTTPS and SSL/TLS fundamentals
  - Input validation with Joi or Zod
  - SQL injection and XSS prevention
  - Rate limiting and DDoS protection
- **API Documentation & Testing**
  - Postman/Insomnia for API testing
  - Swagger/OpenAPI specification
  - Writing unit tests with Jest
  - Integration testing for routes and database operations
  - Test coverage and mocking strategies
  - API versioning documentation
