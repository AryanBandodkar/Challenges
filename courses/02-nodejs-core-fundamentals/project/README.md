# Node.js Core Fundamentals - Learner Project

This project uses challenge stubs only. Learners implement each challenge in `src/challenges/*` and validate through review automation.

## Module Coverage

- **Node.js Architecture & Core APIs**
  - Node.js runtime and V8 engine overview
  - Event loop deep dive: phases, microtasks, macrotasks
  - File system module: reading/writing files, streams, buffers
  - Path and OS modules for cross-platform compatibility
  - Process management: process.env, argv, exit codes
  - Child processes and worker threads basics
- **NPM & Package Management**
  - NPM/Yarn fundamentals: package.json, dependencies vs devDependencies
  - Semantic versioning and package lock files
  - Popular utility libraries: lodash, moment/dayjs, dotenv
  - Creating and publishing packages
  - NPM scripts for automation
- **HTTP & Network Programming**
  - Building basic HTTP servers with native http module
  - Request/response objects, headers, status codes
  - Routing implementation from scratch
  - Query parameters and URL parsing
  - Streams for handling large data transfers
- **Error Handling & Debugging**
  - Error types: operational vs programmer errors
  - Global error handlers and uncaught exceptions
  - Debugging with Node debugger and Chrome DevTools
  - Logging best practices: console, file-based logging
  - Environment-specific configurations with dotenv
