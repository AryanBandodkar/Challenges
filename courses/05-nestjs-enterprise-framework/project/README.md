# NestJS Enterprise Framework - Learner Project

This project uses challenge stubs only. Learners implement each challenge in `src/challenges/*` and validate through review automation.

## Module Coverage

- **NestJS Architecture & Core Concepts**
  - Modules: organizing application structure
  - Controllers: handling HTTP requests, decorators
  - Providers and Dependency Injection
  - Services: business logic separation
  - Middleware, guards, interceptors, pipes
  - Exception filters for error handling
- **Advanced NestJS Features**
  - Custom decorators and metadata reflection
  - Database integration with TypeORM/Prisma
  - Repository pattern implementation
  - Validation with class-validator and class-transformer
  - Configuration management with @nestjs/config
  - Logging with built-in logger or Winston
- **Authentication & Authorization**
  - Passport.js integration: local, JWT strategies
  - Role-based access control (RBAC)
  - Guards for route protection
  - Refresh token rotation
  - API key authentication
- **Microservices & Communication**
  - Microservices architecture patterns
  - Message queues with RabbitMQ or Redis
  - Event-driven architecture
  - gRPC vs REST for inter-service communication
  - Service discovery basics
- **Testing in NestJS**
  - Unit testing with Jest: services, controllers
  - E2E testing with Supertest
  - Mocking dependencies and database
  - Test coverage reporting
  - TDD workflow
